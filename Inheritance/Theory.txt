# 🧬 INHERITANCE (OOP) — FULL REVISION

## 1. Definition (Core Idea)

> Inheritance is the process where one class (child) acquires properties and behaviors of another class (parent).

In simple words:

> **“Reuse existing code and extend it.”**

---

# 🧠 Real-Life Analogy (Very Important)

## 👨‍👦 Parent → Child Relationship

A child inherits:

* surname
* genetic traits
* some behaviors

But also has:

* own personality
* extra abilities

---

## Example:

Parent class:

```text
Human
- eat
- sleep
```

Child class:

```text
Student
- eat (inherited)
- sleep (inherited)
- study (new)
```

👉 Student does NOT rewrite eat/sleep
👉 It just **inherits them**

---

# 🏗️ Basic C++ Syntax

```cpp id="p1a2b3"
class Parent {
public:
    void show() {
        cout << "Parent class" << endl;
    }
};

class Child : public Parent {
public:
    void display() {
        cout << "Child class" << endl;
    }
};
```

Usage:

```cpp id="c4d5e6"
Child c;

c.show();    // inherited from Parent
c.display(); // own function
```

---

# 🔑 Types of Inheritance (VERY IMPORTANT)

## 1. Single Inheritance

One parent → one child

```cpp id="s1"
class A {};
class B : public A {};
```

---

## 2. Multilevel Inheritance

Chain like a family tree

```cpp id="s2"
class A {};
class B : public A {};
class C : public B {};
```

👉 C gets everything from B and A

---

## 3. Multiple Inheritance

One child → multiple parents

```cpp id="s3"
class A {};
class B {};
class C : public A, public B {};
```

---

## 4. Hierarchical Inheritance

One parent → many children

```cpp id="s4"
class A {};
class B : public A {};
class C : public A {};
```

---

## 5. Hybrid Inheritance

Combination of above types

---

# 🔐 Access Control in Inheritance

Very important concept.

| Parent Member | Public Inheritance | Protected Inheritance | Private Inheritance |
| ------------- | ------------------ | --------------------- | ------------------- |
| public        | public             | protected             | private             |
| protected     | protected          | protected             | private             |
| private       | not accessible     | not accessible        | not accessible      |

---

# 🧠 Simple Rule

> Private members are NOT inherited directly.

They exist, but cannot be accessed.

---

# 🧪 Example (Public Inheritance)

```cpp id="p5"
class Parent {
public:
    int x = 10;
};

class Child : public Parent {
public:
    void show() {
        cout << x << endl;
    }
};
```

# 🔥 Why Inheritance is Needed

Without inheritance:

```cpp id="n1"
class Student {
    eat()
    sleep()
    study()
};

class Teacher {
    eat()
    sleep()
    teach()
};
```

👉 duplication of code ❌

---

With inheritance:

```cpp id="n2"
class Human {
public:
    void eat() {}
    void sleep() {}
};

class Student : public Human {
public:
    void study() {}
};

class Teacher : public Human {
public:
    void teach() {}
};
```

👉 reusable + clean ✔

---

# 🧱 Constructor Order in Inheritance (IMPORTANT)

```cpp id="n3"
class A {
public:
    A() {
        cout << "A constructor" << endl;
    }
};

class B : public A {
public:
    B() {
        cout << "B constructor" << endl;
    }
};
```

Output:

```text
A constructor
B constructor
```

👉 Parent constructor runs first

---

# 💀 Destructor Order (Reverse)

```text
Child destructor → Parent destructor
```

Because cleanup happens bottom-up.

# 🧠 Key Interview Points

### ✔ Inheritance means:

Reuse + extend existing class

### ✔ Benefits:

* Code reuse
* Less duplication
* Better structure
* Easy maintenance

### ✔ Rule:

* Private members are not directly accessible
* Constructors are not inherited
* Destructor order is reverse
